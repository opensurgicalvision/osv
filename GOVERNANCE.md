# Project Governance

## 1. Leadership Structure
- **Scientific Lead (R0):** Guides overall scientific vision, paper review, and academic collaborations.
- **Clinical Lead (RC):** Practicing surgeon holding absolute authority on clinical interpretations, anatomical definitions, and boundary adjudications.
- **Technical Lead (R1):** Architecture decisions, code review quality, and RFC management.

## 2. Decision Making
- Routine development: Lazy consensus on GitHub Issues / PRs.
- Major changes: Architecture Decision Records (ADRs) and Request for Comments (RFCs).
- Transition to Technical Steering Committee (TSC) in Phase 4.

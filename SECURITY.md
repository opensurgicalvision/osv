# Security & Privacy Policy

## Reporting a Vulnerability or PHI Leak
If you discover a security vulnerability, API key exposure, or any potential Protected Health Information (PHI) in this repository:
1. **DO NOT** open a public GitHub issue.
2. Email the Security & Safety Team immediately at: `opensurgicalvision@proton.me`.
3. We will acknowledge receipt within 24 hours and provide an remediation timeline.

## PHI Defense & De-identification
All PRs are scanned with automated tools for DICOM private tags, burned-in text, and high-entropy credentials.

# Educational Track & Tutorials

Interactive Jupyter notebooks for getting started with surgical computer vision:
- `01_quickstart_datasets.ipynb`: Loading laparoscopic datasets with zero patient leakage.
- `02_surgical_augmentations.ipynb`: Applying L1 and L2 smoke/blood transformations.
- `03_baseline_segmentation.ipynb`: Fine-tuning SAM 2 on surgical instruments.
- `04_latency_and_tensorrt.ipynb`: Exporting models to ONNX & TensorRT for <=50ms edge inference.
